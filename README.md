Эта программа решает квадратные уравнения
При входе программа предлагает выбрать один из двух режимов: тестирование или использование.
Тестирование доступно как в форме автотестов, так и с помощью собственного файла.
Тестовый файл должен содержать только числа, расоложенные в следующем порядке: коэффициенты а, b, c, количество корней(0 если корней нет, 10 если корень единственный и уравнение линейное,
11 если корень единственный, 2 если корня 2, 3 если бесконечность корней), х1 и х2.
В режиме использования можно выбрать ввод коэффициентов с клавиатуры или из файла. В файле для ввода должны быть числа a b c.
Также можно выбрать вывод коэффициентов на монитор и в файл.
